ATUALIZAÇÃO AVISTAMENTOS VIP — BENTO PANTANAL

O Supabase já está preparado. Os arquivos do site ainda precisam ser publicados, pois a integração GitHub recusou a gravação com erro 403.

1. Extraia este ZIP.
2. No repositório GuiBRA985/Pantanal, abra a branch main e use Add file > Upload files.
3. Arraste as pastas css, js, guias, supabase e docs para a raiz do repositório, preservando os caminhos. Confirme a substituição dos dois arquivos existentes e faça Commit changes.
4. Aguarde a publicação do GitHub Pages. Abra o perfil VIP e toque em Avistamentos.

Exemplo: https://pantanal.bento.host/guias/avistamentos/?slug=guilherme-barros-arantes
